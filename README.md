# PolypClean Pathway — Digital Prototype

GitHub-ready static site built on the Nerfies project-page structure for the ENEC Student Challenge.

## Demo video
The demo is bundled at `static/videos/demo.mp4`. No Google Drive or YouTube link is required for playback on GitHub Pages.

## Publish to `mnehan67/enec-jelly`
This package is intentionally arranged with `index.html` at the repository root. Upload/push **the contents of this folder**, not a parent folder.

### Command line
```bash
git init
git branch -M main
git add .
git commit -m "Launch PolypClean digital prototype"
git remote add origin https://github.com/mnehan67/enec-jelly.git
git push -u origin main
```

Then open GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save**.

The project site should then be available at `https://mnehan67.github.io/enec-jelly/` after GitHub Pages finishes deploying.
